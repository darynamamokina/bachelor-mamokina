# bachelor-mamokina

Інтелектуальний пошук товарів в e-commerce на основі природної мови - Clothes search system

Мамокіна Дарина Ігорівна 4CS-42

Колдовський В. В., доцент ІТ СТЕП Університет, кандидат економічних наук

Мій проєкт - це AI-платформа для пошуку одягу в e-commerce, яка розуміє запити природною мовою та підбирає релевантні товари точніше, ніж звичайний пошук за ключовими словами.

інструкція зі встановлення:
1. скопіювати проект з гітхабу
2. запустити команду pip install -r requirements.txt 
3. запустити файл python seed.py
4. в терміналі прописати команду uvicorn main:app --reload
5. відкрити файл frontend.html в браузері
